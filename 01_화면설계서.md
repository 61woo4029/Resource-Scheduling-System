# 화면 설계서 (UI/UX Specification)

## 1. 공통 레이아웃

### 1.1 전체 구조
- **레이아웃**: 전체 화면의 80% 너비, 화면 중앙 정렬
- **최대 너비**: 1600px

```
+------------------------------------------+
|              AppBar (상단바)              |
+--------+--------------------------------+
|        |                                |
| Drawer |         Content Area           |
| (좌측   |         (메인 컨텐츠)           |
|  메뉴)  |                                |
|        |                                |
+--------+--------------------------------+
```

### 1.2 AppBar (상단바)
| 요소 | 위치 | 설명 |
|------|------|------|
| 햄버거 메뉴 | 좌측 | 모바일에서만 표시, Drawer 토글 |
| 시스템 제목 | 중앙-좌측 | "사내 자원관리 시스템" |
| 알림 아이콘 | 우측 | SYSTEM_ADMIN만 표시, 대기 건수 배지 |
| 프로필 아이콘 | 우측 끝 | 클릭 시 드롭다운 메뉴 |

### 1.3 Drawer (좌측 메뉴)
- **너비**: 240px
- **반응형**: 모바일에서는 임시 Drawer, 데스크탑에서는 영구 Drawer

#### 메뉴 구성
```
[자원관리 시스템]
─────────────────
📊 대시보드
👤 마이페이지
💻 자산 관리
🏢 회의실 예약
🚗 법인차량 예약
─────────────────
[관리] (SYSTEM_ADMIN만)
👥 사용자 관리
🏛️ 부서 관리
🔐 권한 관리
📋 메뉴 관리
```

## 2. 로그인 페이지 (/login)

### 2.1 화면 구성
```
+--------------------------------+
|                                |
|    +----------------------+    |
|    | 사내 자원관리 시스템  |    |
|    |       로그인         |    |
|    |                      |    |
|    | [이메일 입력]        |    |
|    | [비밀번호 입력]      |    |
|    | □ 로그인 상태 유지   |    |
|    |                      |    |
|    | [    로그인    ]     |    |
|    |                      |    |
|    | 계정이 없으신가요?   |    |
|    |     회원가입         |    |
|    +----------------------+    |
|                                |
+--------------------------------+
```

### 2.2 필드 상세
| 필드명 | 타입 | 필수 | 유효성 검사 |
|--------|------|------|------------|
| 이메일 | text | O | 이메일 형식 (xxx@xxx.xx) |
| 비밀번호 | password | O | 필수 입력 |

### 2.3 동작
- 로그인 성공 → 대시보드로 이동
- 로그인 실패 → 에러 메시지 Alert 표시
- "회원가입" 클릭 → /register로 이동

### 6.6 시간 슬롯 설정
- **시작 시간**: 08:00
- **종료 시간**: 20:00
- **간격**: 30분
- **예약 셀 클릭**: 해당 시간대로 예약 다이얼로그 오픈
- **예약된 셀 클릭**: 상세 보기/수정/취소 옵션

### 6.7 드래그 시간 선택 기능
- 빈 시간대를 마우스로 드래그하여 연속된 시간 범위 선택 가능
- 드래그 중인 셀은 파란색(`#bbdefb`)으로 하이라이트
- 마우스를 테이블 밖으로 이동하면 드래그 취소
- 드래그 완료 시 선택한 시간 범위로 예약 다이얼로그 자동 열림
- 일별 보기: 같은 회의실 내에서만 드래그 가능
- 주별 보기: 같은 날짜 내에서만 드래그 가능

### 6.8 예약 셀 병합 (rowSpan)
- 동일한 예약이 여러 시간대에 걸쳐 있으면 하나의 셀로 병합 표시
- 병합된 셀에 회의 제목, 예약자, 시간 표시
- 일별/주별 보기 모두 적용

### 6.9 예약 색상 선택
- 예약 등록/수정 시 표시 색상 선택 가능
- 10가지 파스텔톤 색상 제공 (스카이블루, 라벤더, 민트, 코랄핑크 등)
- 색상은 로컬 스토리지에 저장되어 유지
- 기본 색상: 스카이블루 (#dbeafe)

## 11. 반응형 브레이크포인트

| 크기 | 범위 | 설명 |
|------|------|------|
| xs | 0-599px | 모바일 |
| sm | 600-899px | 태블릿 |
| md | 900-1199px | 소형 데스크탑 |
| lg | 1200px+ | 대형 데스크탑 |

### 반응형 동작
- **모바일 (xs)**: Drawer가 임시(temporary)로 변경, 햄버거 메뉴로 토글
