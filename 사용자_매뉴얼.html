🏢 자원관리시스템
사용자 매뉴얼

사내 자산·회의실·법인차량을 통합 관리하는 웹 애플리케이션 사용 안내서입니다.

📅 2026년 3월 🌐 http://localhost:3000 👥 일반 사용자 · 관리자 통합
📋

시스템 개요

자원관리시스템은 회사 내 자산, 회의실, 법인차량을 한 곳에서 편리하게 관리할 수 있는 웹 기반 플랫폼입니다.

🔑

권한 체계

시스템은 3단계 권한으로 구분되며, 권한에 따라 접근 가능한 메뉴와 기능이 달라집니다.

권한 역할명 접근 가능 기능
일반 사용자 USER 자산 조회, 회의실 예약, 법인차량 예약, 마이페이지
자산 관리자 ASSET_ADMIN 일반 사용자 기능 + 자산 등록·수정·삭제·엑셀 업로드
시스템 관리자 SYSTEM_ADMIN 전체 기능 + 사용자·부서·권한·메뉴 관리
⚠️ 권한 상향이 필요한 경우 마이페이지 → 권한 신청 메뉴를 통해 신청하고, 시스템 관리자의 승인을 받아야 합니다.
🔐

로그인 / 로그아웃

로그인

  1. 1브라우저에서 http://localhost:3000 접속 시 자동으로 로그인 페이지로 이동합니다.
  2. 2이메일과 비밀번호를 입력합니다.
  3. 3로그인 버튼을 클릭합니다.
  4. 4로그인 성공 시 대시보드 화면으로 이동합니다.
⚠️ 이메일 또는 비밀번호가 올바르지 않으면 오류 메시지가 표시됩니다. 대소문자를 정확히 입력해 주세요.

로그아웃

  1. 1화면 왼쪽 사이드바 하단의 로그아웃 버튼을 클릭합니다.
  2. 2로그인 페이지로 이동하며 세션이 종료됩니다.
💡 로그인 상태는 브라우저에 저장됩니다. 로그인을 유지하려면 브라우저를 닫지 마세요. 보안을 위해 사용 후에는 반드시 로그아웃하세요.
🏠

대시보드

로그인 후 최초로 표시되는 메인 화면입니다. 사용자 이름과 역할이 상단에 표시되며, 주요 기능으로 바로 이동할 수 있는 퀵 메뉴가 제공됩니다.

📌 화면 구성
• 상단 환영 메시지: 로그인한 사용자 이름과 역할 표시
• 좌측 사이드바: 전체 메뉴 목록 (권한에 따라 표시 항목 다름)
• 퀵 메뉴 카드: 회의실 예약하기 / 법인차량 예약하기 바로가기
• 관리자 전용: 사용자 관리, 부서 관리, 권한 관리, 메뉴 관리 메뉴 표시
💻

자산 관리

회사 내 IT 자산(데스크탑, 노트북, 서버, 모니터)을 조회하고 관리합니다.

자산 조회 (전체 사용자)

  1. 1사이드바에서 자산 관리를 클릭합니다.
  2. 2상단 탭(데스크탑 / 노트북 / 서버 / 모니터)에서 카테고리를 선택합니다.
  3. 3검색 조건(자산관리번호, 사용자명, 상태)을 입력한 후 검색 버튼을 클릭합니다.
  4. 4목록에서 원하는 자산 정보를 확인합니다.
📌 컬럼 안내
• 공통: NO. / 자산관리번호 / 사용자명 / 제조사 / 모델명 / S/N / 상태
• 데스크탑·노트북·서버 추가: OS / CPU / RAM
• 모니터: OS·CPU·RAM 컬럼 미표시

자산 등록 자산 관리자 이상

  1. 1자산 등록 버튼을 클릭합니다.
  2. 2등록 다이얼로그에서 항목을 입력합니다.
    자산관리번호* 사용자명* 은 필수 입력입니다.
  3. 3저장 버튼을 클릭하면 목록에 즉시 반영됩니다.

자산 수정 자산 관리자 이상

  1. 1목록에서 수정할 자산 행의 ✏️ 아이콘을 클릭합니다.
  2. 2수정 다이얼로그에서 항목을 변경합니다.
  3. 3저장 버튼을 클릭합니다.

자산 삭제 자산 관리자 이상

  1. 1목록에서 삭제할 자산 행의 🗑️ 아이콘을 클릭합니다.
  2. 2확인 메시지에서 확인을 클릭하면 삭제됩니다.
⚠️ 여러 자산을 한꺼번에 삭제하려면 목록의 체크박스를 선택한 후 선택 삭제 버튼을 클릭하세요.

엑셀 일괄 업로드 자산 관리자 이상

  1. 1템플릿 버튼을 클릭해 엑셀 양식을 다운로드합니다.
  2. 2양식에 자산 정보를 입력하고 저장합니다.
  3. 3일괄 업로드 버튼을 클릭하고 작성한 파일을 선택합니다.
  4. 4업로드 버튼을 클릭하면 처리 결과(전체/성공/실패 건수)가 표시됩니다.

엑셀 다운로드 자산 관리자 이상

엑셀 다운로드 버튼을 클릭하면 현재 카테고리의 전체 자산 목록이 .xlsx 파일로 저장됩니다.

🏛️

회의실 예약

스케줄러 형태로 회의실 예약 현황을 확인하고 예약을 생성·취소할 수 있습니다.

예약 현황 조회

  1. 1사이드바에서 회의실 예약을 클릭합니다.
  2. 2일별 / 주별 탭을 선택합니다.
  3. 3날짜 이동 버튼(〈 〉)으로 원하는 날짜로 이동하거나 오늘 버튼으로 오늘 날짜로 돌아옵니다.
  4. 4스케줄러 표에서 회의실별 예약 현황(시간대·예약자)을 확인합니다.
📌 스케줄러 표 안내
• 세로축: 시간대 (08:00 ~ 19:30, 30분 단위)
• 가로축: 회의실별 칸
• 빈 칸: 예약 가능한 슬롯
• 색상 블록: 예약된 슬롯 (예약자명·시간 표시)

예약 생성

  1. 1스케줄러에서 예약하려는 빈 시간 칸을 클릭합니다.
  2. 2예약 다이얼로그에서 정보를 입력합니다.
    • 회의실 선택 / 회의 제목 / 참석 인원 / 시작·종료 시간
  3. 3예약 버튼을 클릭하면 예약이 완료됩니다.
✅ 예약 성공 시 "예약이 완료되었습니다." 메시지가 표시되고 스케줄러에 즉시 반영됩니다.

예약 취소

  1. 1스케줄러에서 본인이 예약한 블록의 삭제(×) 버튼을 클릭합니다.
  2. 2확인 후 예약이 취소됩니다.
⚠️ 타인의 예약은 취소할 수 없습니다. 시스템 관리자에게 문의하세요.
🚗

법인차량 예약

회사 보유 법인차량의 예약 현황을 조회하고 예약을 생성할 수 있습니다.

예약 현황 조회

  1. 1사이드바에서 법인차량 예약을 클릭합니다.
  2. 2일별 / 주별 탭을 선택합니다.
  3. 3날짜 이동 버튼으로 원하는 날짜로 이동합니다.
  4. 4스케줄러 표에서 차량별 예약 현황을 확인합니다.
📌 차량별 색상 구분
화면 상단에 차량별 색상 범례가 표시되어 여러 차량의 예약을 색상으로 구별할 수 있습니다.

예약 생성

  1. 1예약하기 버튼을 클릭합니다.
  2. 2예약 다이얼로그에서 정보를 입력합니다.
    • 차량 선택 / 예약일 / 시작 시간 / 종료 시간 / 목적 / 행선지
    • 운전자는 로그인 사용자 이름으로 자동 입력됩니다.
  3. 3저장 버튼을 클릭하면 예약이 완료됩니다.
✅ 예약 성공 시 "예약이 완료되었습니다." 메시지가 표시되고 스케줄러에 즉시 반영됩니다.

예약 취소

  1. 1스케줄러에서 본인이 예약한 블록의 삭제(×) 버튼을 클릭합니다.
  2. 2확인 후 예약이 취소됩니다.
⚠️ 이미 지난 시간대의 예약은 취소할 수 없습니다.
👤

마이페이지

내 계정 정보 수정, 비밀번호 변경, 권한 신청을 할 수 있습니다.

프로필 수정

  1. 1사이드바에서 마이페이지를 클릭합니다.
  2. 2프로필 탭에서 이름, 부서 등 정보를 수정합니다.
  3. 3저장 버튼을 클릭합니다.

비밀번호 변경

  1. 1비밀번호 변경 탭을 클릭합니다.
  2. 2현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력합니다.
  3. 3변경 버튼을 클릭합니다.
⚠️ 새 비밀번호와 확인이 일치하지 않으면 변경되지 않습니다.

권한 신청

  1. 1권한 신청 탭을 클릭합니다.
  2. 2권한 신청 버튼을 클릭합니다.
  3. 3신청 역할(자산 관리자 또는 시스템 관리자)과 신청 사유를 입력합니다.
  4. 4신청 버튼을 클릭합니다.
  5. 5관리자 승인 후 권한이 변경됩니다. 신청 내역과 처리 상태를 탭에서 확인할 수 있습니다.
👥

사용자 관리 시스템 관리자

전체 사용자 계정을 조회하고 역할·부서·상태를 관리합니다.

사용자 목록 조회

  1. 1사이드바에서 사용자 관리를 클릭합니다.
  2. 2이름·이메일·부서·역할 등으로 검색할 수 있습니다.

사용자 수정

  1. 1목록에서 수정할 사용자의 ✏️ 버튼을 클릭합니다.
  2. 2이름, 부서, 역할, 활성화 여부 등을 변경합니다.
  3. 3저장 버튼을 클릭합니다.
💡 역할 변경은 이 화면에서 즉시 적용 가능합니다. 권한 신청 승인과 무관하게 관리자가 직접 변경할 수 있습니다.

사용자 삭제

  1. 1목록에서 삭제할 사용자의 🗑️ 버튼을 클릭합니다.
  2. 2확인 메시지에서 확인을 클릭합니다.
⚠️ 삭제된 계정은 복구할 수 없습니다. 신중하게 처리해 주세요.
🏗️

부서 관리 시스템 관리자

회사 부서를 등록·수정·삭제합니다. 사용자 등록 및 프로필 수정 시 부서 목록에 반영됩니다.

부서 등록

  1. 1사이드바에서 부서 관리를 클릭합니다.
  2. 2부서 등록 버튼을 클릭하고 부서명을 입력합니다.
  3. 3저장 버튼을 클릭합니다.

부서 수정 / 삭제

목록에서 해당 부서의 ✏️(수정) 또는 🗑️(삭제) 버튼을 클릭합니다.

⚠️ 소속 사용자가 있는 부서는 삭제되지 않을 수 있습니다.
🛡️

권한 신청 관리 시스템 관리자

사용자가 신청한 권한 변경 요청을 승인하거나 거절합니다.

신청 목록 조회 및 처리

  1. 1사이드바에서 권한 관리를 클릭합니다.
  2. 2신청 목록에서 신청자·현재 역할·신청 역할·사유를 확인합니다.
  3. 3승인 또는 거절 버튼을 클릭합니다.
  4. 4코멘트(선택)를 입력하고 처리를 확정합니다.
처리 결과설명
승인즉시 해당 사용자의 역할이 신청 역할로 변경됩니다.
거절역할 변경 없이 신청이 종료됩니다. 코멘트로 사유를 전달할 수 있습니다.
📂

메뉴 관리 시스템 관리자

사이드바에 표시되는 메뉴 항목의 노출 여부·순서·접근 권한을 관리합니다.

메뉴 수정

  1. 1사이드바에서 메뉴 관리를 클릭합니다.
  2. 2목록에서 수정할 메뉴의 ✏️ 버튼을 클릭합니다.
  3. 3메뉴명, 경로, 표시 순서, 최소 권한, 노출 여부를 수정합니다.
  4. 4저장 버튼을 클릭합니다.
⚠️ 메뉴 노출 여부를 끄면 해당 권한의 사용자에게 메뉴가 표시되지 않습니다. 주의해서 변경하세요.
❓

자주 묻는 질문

Q. 비밀번호를 잊었습니다.

현재 비밀번호 찾기 기능은 지원되지 않습니다. 시스템 관리자에게 비밀번호 초기화를 요청해 주세요.

Q. 자산 등록 시 "이미 등록된 자산관리번호" 오류가 납니다.

자산관리번호는 시스템 내에서 고유해야 합니다. 중복되지 않는 번호를 사용하거나 기존 자산을 먼저 삭제해 주세요.

Q. 회의실 예약이 되지 않습니다.

선택한 시간대에 이미 예약이 있는 경우 예약할 수 없습니다. 스케줄러에서 빈 슬롯을 확인한 후 예약해 주세요.

Q. 권한 신청 후 언제 반영되나요?

시스템 관리자가 승인하는 즉시 반영됩니다. 승인 여부는 마이페이지 → 권한 신청 탭에서 확인할 수 있습니다.

Q. 엑셀 업로드 후 일부 데이터가 실패했습니다.

업로드 결과 다이얼로그에서 실패 행 번호와 사유를 확인할 수 있습니다. 오류를 수정한 후 해당 행만 다시 업로드하세요.

Q. 로그인 후 화면이 비어 있거나 메뉴가 보이지 않습니다.

브라우저를 새로고침(F5)하거나 로그아웃 후 다시 로그인해 보세요. 문제가 지속되면 관리자에게 문의해 주세요.
